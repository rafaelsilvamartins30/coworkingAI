# Prompt — Tarefa grande

Use para feature grande, mudança estrutural, refatoração de módulo, autenticação, troca de biblioteca ou alteração com risco alto.

```md
Tarefa:
[descreva a mudança grande]

Contexto:
Leia `AGENTS.md` e `CONTEXTO.MD` se existirem.

Objetivo:
[o que queremos alcançar]

Fora do escopo:
[o que não deve ser feito agora]

Restrições:
- Não implemente ainda.
- Primeiro gere um plano em etapas pequenas.
- Cada etapa deve ser testável e revisável separadamente.
- Aponte decisões técnicas que precisam ser tomadas pelo usuário.
- Para cada decisão, apresente opções com vantagens, desvantagens, trade-offs e riscos.

Plano esperado:
1. entendimento do problema;
2. arquivos prováveis;
3. etapas de implementação;
4. validação de cada etapa;
5. riscos;
6. documentação que precisará ser atualizada.

Depois do plano:
- Aguarde aprovação.
- Implemente somente uma etapa por vez.
```
