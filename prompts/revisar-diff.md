# Prompt — Revisar diff

Use depois de qualquer alteração relevante.

```md
Revise o diff atual.

Não implemente nada nesta etapa.

Procure:
1. mudança fora do escopo;
2. bug óbvio;
3. quebra de contrato público;
4. regra de negócio alterada sem motivo;
5. complexidade desnecessária;
6. teste faltando;
7. documentação desatualizada;
8. nomes ruins ou responsabilidades misturadas.

Retorne:
- problemas encontrados;
- severidade de cada problema;
- sugestões objetivas de correção;
- se o diff está aceitável ou não.
```
